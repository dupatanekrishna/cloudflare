This report refreshes only when you click Load report. It counts events, not people. Sessions are anonymous IDs per browser tab; the same person may create several sessions, and sessions across incognito tabs or devices cannot be linked. Total active time sums visible-tab events; the per-page and per-session averages divide that total by all page views or tab sessions and can fall when manual page-view tests or quick exits add visits with little time. Active time is approximate and is sent about every 15 seconds while a site page is visible. Browser, device, and operating-system panels count page views and are inferred from the browser request, not unique visitors. Daily grouping uses UTC. External-link clicks show only the destination host, not visits on GitHub or other external sites. Location is approximate. The report does not show names, IP addresses, chat messages, or form entries. The token stays in this page's memory and is not saved by the dashboard.
